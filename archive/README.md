# Archived material (not the canonical camera-ready experiments)

The repository's main reproducibility package is [HFM-benchmark_code.zip](../HFM-benchmark_code.zip).
Use the root README instructions to reproduce the revised-paper experiments.

- **legacy/** contains old standalone GD+M/FLO/HNF or HFM scripts and their instructions.
- **supplementary/** contains older additional experimental CSVs and a descriptive analyzer.

These files are preserved for traceability. Their protocols and outputs should not be substituted for the revised manuscript's reference implementation and results.
